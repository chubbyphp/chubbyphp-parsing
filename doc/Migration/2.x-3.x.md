# 2.x to 3.x

Removed all APIs which were deprecated in 2.x. If your code runs on the latest 2.x
release without deprecation warnings, it will work with 3.x without changes.

## Removed classes

| Removed                                     | Replacement                                            |
|---------------------------------------------|--------------------------------------------------------|
| `Chubbyphp\Parsing\Schema\AbstractSchema`   | `Chubbyphp\Parsing\Schema\AbstractSchemaInnerParse`    |
| `Chubbyphp\Parsing\Schema\LiteralSchema`    | `Chubbyphp\Parsing\Schema\ConstSchema`                 |

## Removed methods

### `Parser`

| Removed              | Replacement       |
|----------------------|-------------------|
| `literal($literal)`  | `const($const)`   |

### `ObjectSchema` / `AssocSchema`

| Removed              | Replacement          |
|----------------------|----------------------|
| `optional($optional)`| `required($required)`|

Beware the inverted semantics: with `required($required)` the listed fields must be
present and all other fields are optional.

### `ArraySchema`

| Removed                  | Replacement              |
|--------------------------|--------------------------|
| `length($length)`        | `exactItems($exactItems)`|
| `minLength($minLength)`  | `minItems($minItems)`    |
| `maxLength($maxLength)`  | `maxItems($maxItems)`    |
| `includes($includes)`    | `contains($contains)`    |

### `FloatSchema` / `IntSchema`

| Removed         | Replacement                            |
|-----------------|----------------------------------------|
| `gte($gte)`     | `minimum($minimum)`                    |
| `gt($gt)`       | `exclusiveMinimum($exclusiveMinimum)`  |
| `lt($lt)`       | `exclusiveMaximum($exclusiveMaximum)`  |
| `lte($lte)`     | `maximum($maximum)`                    |
| `nonNegative()` | `minimum(0)` / `minimum(0.0)`          |
| `positive()`    | `exclusiveMinimum(0)` / `exclusiveMinimum(0.0)` |
| `negative()`    | `exclusiveMaximum(0)` / `exclusiveMaximum(0.0)` |
| `nonPositive()` | `maximum(0)` / `maximum(0.0)`          |

### `StringSchema`

| Removed                | Replacement            |
|------------------------|------------------------|
| `includes($includes)`  | `contains($contains)`  |
| `domain()`             | `hostname()`           |
| `match($match)`        | `pattern($pattern)`    |
| `regexp($regexp)`      | `pattern($pattern)`    |
| `url()`                | `uri()`                |

## Removed error constants

The error constants of the removed methods were removed as well, for example
`ArraySchema::ERROR_MIN_LENGTH_CODE` (use `ArraySchema::ERROR_MIN_ITEMS_CODE`)
or `StringSchema::ERROR_URL_CODE` (use `StringSchema::ERROR_URI_CODE`).

## Interface changes

Only relevant if you implement the interfaces yourself:

- `ParserInterface` now declares `allOf()`, `any()`, `assoc()`, `const()`, `if()`,
  `not()` and `oneOf()` as real methods (previously `@method` annotations).
- `ParserInterface::object()` gained the `bool $construct = false` parameter.
- `ObjectSchemaInterface` now declares `required()` and `additionalProperties()`.
- `SchemaInterface` now declares `default()`.

old:

```php
<?php

declare(strict_types=1);

namespace App;

use Chubbyphp\Parsing\Parser;

$p = new Parser();

$schema = $p->object([
    'name' => $p->string()->minLength(1),
    'email' => $p->string()->url(),
    'age' => $p->int()->gte(0)->lt(150),
    'tags' => $p->array($p->string())->minLength(1)->includes('php'),
    'type' => $p->literal('user'),
])->optional(['tags']);
```

new:

```php
<?php

declare(strict_types=1);

namespace App;

use Chubbyphp\Parsing\Parser;

$p = new Parser();

$schema = $p->object([
    'name' => $p->string()->minLength(1),
    'email' => $p->string()->uri(),
    'age' => $p->int()->minimum(0)->exclusiveMaximum(150),
    'tags' => $p->array($p->string())->minItems(1)->contains('php'),
    'type' => $p->const('user'),
])->required(['name', 'email', 'age', 'type']);
```
